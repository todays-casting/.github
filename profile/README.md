# 🎬 Today’s Casting

## “오늘의 나를 하나의 캐스팅 카드로 기록하는 감성 아카이빙 서비스”

일상 기록을 더 쉽고 재미있게,
사용자의 하루를 장르와 캐릭터 콘셉트로 표현하는 AI 기반 감성 기록 플랫폼

---

## 📘 프로젝트 개요

최근 개인 기록 서비스는 단순한 메모를 넘어
사용자의 감정, 취향, 하루의 분위기를 시각적으로 남기는 방향으로 발전하고 있습니다.

**Today’s Casting**은 사용자가 오늘의 기분과 상황을 입력하면,
AI가 이를 분석해 오늘의 장르, 캐릭터 콘셉트, 캐스팅 카드 형태로 변환해주는 서비스입니다.

사용자는 자신의 하루를 영화나 드라마 속 한 장면처럼 기록하고,
캘린더와 히스토리를 통해 지난 감정과 기록을 한눈에 확인할 수 있습니다.

---

## 🎯 프로젝트 제안 배경

기존 일기 서비스는 텍스트 입력 중심으로 구성되어 있어
꾸준히 사용하기 어렵고, 기록 자체가 부담스럽게 느껴질 수 있습니다.

또한 감정 기록 앱은 기능적으로는 유용하지만,
사용자의 흥미를 지속적으로 유도하는 요소가 부족한 경우가 많습니다.

👉 따라서 본 프로젝트는

> **“AI 기반 감정 분석 + 캐스팅 카드 형식의 시각적 기록”**

을 결합하여, 사용자가 부담 없이 하루를 기록하고
자신만의 감성 아카이브를 만들어갈 수 있는 서비스를 목표로 합니다.

---

## 🧩 요구사항 요약

### ✍️ 오늘의 기록 입력

* 사용자는 오늘의 기분, 있었던 일, 기억에 남는 순간을 입력 가능
* 간단한 텍스트 입력만으로 오늘의 분위기 기록
* 입력된 내용을 바탕으로 AI 분석 수행
* 기록 완료 후 오늘의 캐스팅 카드 생성

---

### 🎭 AI 캐스팅 카드 생성

* 사용자의 기록을 기반으로 오늘의 장르 추천
* 하루의 분위기에 어울리는 캐릭터 콘셉트 생성
* 감정 키워드 및 한 줄 요약 제공
* 카드 형태의 시각적 결과 제공
* 사용자는 생성된 카드를 저장하거나 다시 확인 가능

---

### 📅 캘린더 기반 기록 관리

* 날짜별 기록 확인 가능
* 캘린더에서 과거에 생성한 캐스팅 카드 조회
* 마음에 드는 카드는 즐겨찾기 가능
* 사용자가 자신의 감정 흐름을 쉽게 파악할 수 있도록 구성

---

### 🗂️ 히스토리 및 저장 기능

* 생성한 캐스팅 카드 목록 확인
* 최근 기록 및 이전 기록 조회
* 찜한 카드만 따로 확인 가능
* 사용자의 기록을 감성 아카이브처럼 관리

---

### 👤 마이페이지

* 사용자 프로필 확인
* 찜한 카드 개수 확인
* 알림 설정 관리
* 계정 및 서비스 설정 관리

---

### 🔐 로그인 및 회원 관리

* 로컬 로그인 지원
* 카카오톡 회원가입 및 로그인 지원
* 사용자별 기록 데이터 관리

## 🚀 기대 효과

### 감정 기록의 진입 장벽 완화

긴 글을 쓰지 않아도 간단한 입력만으로
오늘의 하루를 시각적인 카드로 기록할 수 있습니다.

### 꾸준한 사용 유도

AI가 매일 다른 장르와 캐릭터 콘셉트를 제공하여
사용자가 기록하는 과정에서 재미를 느낄 수 있습니다.

### 개인 감성 아카이브 형성

캘린더와 히스토리를 통해
사용자는 자신의 감정 변화와 하루의 흐름을 자연스럽게 돌아볼 수 있습니다.

### 차별화된 기록 경험 제공

단순 일기나 감정 체크가 아닌,
“오늘의 나를 캐스팅한다”는 콘셉트로 기존 기록 서비스와 차별화됩니다.

```text
[Client]

        ↓ REST API

User / Auth / Record / Card / Calendar / History

        ↓ AI Request

[AI Server]
Emotion Analysis / Genre Recommendation / Casting Card Generation

        ↓

[Database]
User Data / Record Data / Card Data / Favorite Data
```
